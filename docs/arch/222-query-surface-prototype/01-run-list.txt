# STATE carries the block reason in parentheses, exactly as the existing
# `formatState` renders `queued #2 (vendor:fake)` in packages/cli/src/commands/tasks.ts.
# Four shapes, one per #218 block reason:
#
#   blocked (gate)         waiting at a declared gate
#   blocked (loop 2/2)     loop budget exhausted, `while` still true
#   blocked (2/3 slots)    fan-out below its `success` policy
#   blocked (spawn)        delegate() threw; see `parley run status <run>`
#
# `completed (fork r3)` marks a run that has been forked (#221) — the parent is
# immutable, but a reader scanning the list needs to know the story continues.
#
# TASKS is settled/total across the whole run, so a live fan-out reads 1/3.
# ITER is the run's current iteration (#217), not a budget: the budget is a
# property of whichever loop edge is live and shows up in the block reason.
