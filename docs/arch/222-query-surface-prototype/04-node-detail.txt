# Node detail — one node, one iteration
#
# `parley run status <run> --node <id> [--iteration <n>] [--slot <name>]`.
# A flag on the same command, not a new subcommand: `--node` is a zoom on the
# summary, the way `parley status <task>` is a zoom on `parley status`.
# `--iteration` defaults to the latest.
#
# This is where child-authored prose lives for a fan-out - the summary refuses
# to merge twelve gists, so this view lists them.
